<p align="center">
  UltimMC é um launcher personalizado para Minecraft que permite gerenciar múltiplas instâncias e usar contas offline ("pirata") mantendo-se o mais fiel possível ao original.
</p>

> [!IMPORTANT]
> Este projeto é um **fork** do MultiMC. </br></br>
> Este software é fornecido sem qualquer garantia, portanto, por favor, não entre em contato. </br></br>

## Instalação e Uso

1. Escolha o download correto para o seu sistema.
2. Extraia o arquivo no diretório desejado.
3. Execute o `UltimMC`.
4. Vá para as configurações de conta.
5. Escolha uma das opções:
   - **A.** Clique em "Add Local" e insira o nome de usuário desejado (pode ser qualquer um).
   - **B.** Clique em "Add Ely.by" e adicione sua conta Ely.by inserindo seu e-mail e senha.
6. Salve as configurações.
7. Agora aproveite o Launcher!
